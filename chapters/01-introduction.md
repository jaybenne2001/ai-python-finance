# 1. Introduction

Python turns finance from spreadsheet guesswork into reproducible analysis, and AI extends it to forecasting and reading unstructured text. A notebook that pulls prices, computes returns and charts risk can be rerun every month with one click; the same logic in Excel gets rebuilt by hand.

This guide is for investors, students and analysts who know basic finance and want working code. Twenty chapters move from core finance in Python (1–11) to AI (12–14) to big-data platforms: Apache Spark, Kafka, Iceberg and Starburst (15–18). Each chapter pairs a concept with a short, runnable example.
